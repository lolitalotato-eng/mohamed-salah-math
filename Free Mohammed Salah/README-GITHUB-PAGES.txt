# محمد صلاح للرياضيات — GitHub Pages version

This is a static version of the website. The math solver runs in the visitor's browser.
It does not require Node.js, a server, an API key, or a running personal computer.

## Publish with GitHub Pages
1. Upload `index.html` to the top level (root) of the public GitHub repository.
2. In the repository, open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

The existing `server.js` and `public` folder can remain in the repository; GitHub Pages will use the root `index.html`.
