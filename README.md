# محمد صلاح للرياضيات — النسخة المجانية

تعمل هذه النسخة بمحرك رياضيات محلي بسيط، ولا تحتاج إلى مفتاح API أو رصيد مدفوع.

## التشغيل على Windows
1. ثبّت Node.js 18 أو أحدث.
2. افتح Command Prompt داخل مجلد المشروع.
3. نفّذ `npm install` مرة واحدة.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

## ما الذي يدعمه المحرك؟
- العمليات الحسابية الأساسية والأقواس.
- المعادلات الخطية البسيطة بمتغير س أو x.
- مساحات المثلث عند إدخال القاعدة والارتفاع.
- إرشادات أساسية لجمع الكسور.

هذه ليست خدمة ذكاء اصطناعي عامة؛ المسائل خارج الأنواع المدعومة ستظهر لها رسالة توضح ذلك. لا تحتاج هذه النسخة إلى ملف `.env` أو مفتاح API.
